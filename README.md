CodeOrbit Tech – Sales Data Analysis Project

1. Project Overview
This project is part of the Data Analyst Internship at CodeOrbit Tech. It demonstrates sales data cleaning, analysis, and visualization using Python, Pandas, Microsoft Excel, and a dashboard.
The main objective is to process a sales dataset, identify important sales trends, calculate key performance indicators (KPIs), and present the findings in a clear and understandable format.

2. Project Objectives
•	Clean and prepare the sales dataset.
•	Identify and handle missing values.
•	Detect and remove duplicate records.
•	Perform sales analysis using Python and Pandas.
•	Calculate important sales performance metrics.
•	Analyse sales by product, category, and region.
•	Present the results using Excel summaries and dashboard visualizations.

5. Data Cleaning Process
The following data-cleaning activities were demonstrated:
1.	Identifying missing values in the dataset.
2.	Handling missing product information.
3.	Filling a missing quantity value with 1 for demonstration purposes.
4.	Identifying and removing duplicate records.
5.	Checking data formatting and preparing the cleaned dataset for analysis.
Note: The missing-value handling decisions are demonstration assumptions and may need to be adjusted if an official dataset is provided.

7. How to Install and Run the Project
Step 1: Install Python
Install Python 3 on your computer.
Step 2: Install Pandas
Open Command Prompt or a terminal and execute:
pip install pandas
Step 3: Open the Project Folder
Open the terminal inside the folder containing the project files.
Step 4: Run the Python Script
Execute the following command:
python sales_analysis.py
Step 5: Check the Output
The script reads raw_sales.csv, performs the data-cleaning and analysis operations, and generates cleaned_sales.csv.

8. Project Dashboard
The project includes a dashboard image named sales_dashboard.png, which presents the sales analysis visually.
The Excel workbook also contains a chart and KPI sheet to help understand the results.

9. Conclusion
This project demonstrates the basic workflow of a data analysis task, starting from raw data cleaning and continuing through data processing, analysis, and visualization.
Python and Pandas were used for data cleaning and analysis, while Microsoft Excel was used to organize and present the results.
The project helped demonstrate how sales data can be transformed into meaningful information through data analysis techniques.
